# Тестовое задание: Real-time Chat Application

## Описание
Разработать веб-приложение для обмена сообщениями в реальном времени. Опционально можно добавить функционал видео-историй (stories).

## Технологический стек
Backend: NestJS + TypeScript
Frontend: SvelteKit + TypeScript
Database: MongoDB
Real-time: Socket.io / WebSocket

## Функциональные требования
1. Авторизация
    1. Регистрация пользователя (email, password, username)
    1. Вход в систему (JWT токены)
    1. Защита приватных роутов
1. Диалоги (обязательно)
    1. Список всех диалогов пользователя
    1. Создание нового диалога с другим пользователем
    1. Отправка текстовых сообщений
    1. Получение сообщений в реальном времени (WebSocket)
1. Пользователи
    1. Список всех пользователей системы
    1. Поиск пользователей по username
    1. Возможность начать диалог с любым пользователем
1. Stories (опционально, будет плюсом)
    1. Запись видео через веб-камеру (до 15 секунд)
    1. Лента историй - список пользователей с активными stories
    1. Автоудаление - stories удаляются через 24 часа

## Технические требования
- Backend (NestJS)
    - REST API для основных операций (auth, users, conversations, messages)
    - WebSocket gateway для real-time сообщений
    - JWT авторизация
    - Валидация входящих данных
    - Базовая обработка ошибок

    - Опционально: 
        - API для stories, загрузка видео (multipart/form-data)
- Frontend (SvelteKit)
    - Svelte stores для состояния (auth, messages, conversations)
    - WebSocket клиент для real-time сообщений
    - Обработка loading и error states
    - Опционально: 
        - Запись видео (MediaRecorder API), 
        - видео плеер, 
        - таймер записи

## Что НЕ требуется
1. Групповые чаты (только 1-на-1 диалоги)
1. Отправка файлов/изображений в чат
1. Редактирование/удаление сообщений
1. Фильтры и эффекты для видео
1. Обработка/конвертация видео на бэкенде
1. Push-уведомления
1. Развертывание в продакшн
1. Сложная UI/UX (достаточно базового функционала)
1. Оптимизация размера видео (можно загружать как есть)

## Ожидаемый результат
1. Репозиторий на GitHub с исходным кодом
1. README с инструкциями по запуску
1. Docker Compose для локального развертывания (опционально, но будет плюсом)
1. Работающее приложение, которое можно запустить локально

## Критерии успеха
1. Обязательно:
    1. Приложение запускается и работает
    1. Можно зарегистрироваться и войти в систему
    1. Можно обмениваться сообщениями в реальном времени
    1. Сообщения приходят через WebSocket без перезагрузки страницы
    1. Код структурирован и читаем
    1. Базовая обработка ошибок присутствует
1. Будет плюсом:
    1. Реализован функционал stories (запись, просмотр, автоудаление)
    1. Docker Compose для быстрого запуска
    1. Тесты (хотя бы базовые)
