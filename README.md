# Wisebits Chat

## Как развернуть систему

### Необходимые условия: 
- Docker + Docker Compose
- Node.js
- pnpm

### Установка зависимостей

```bash
pnpm install
```

## Запуск в режиме продакшена

```bash
pnpm start
```

Это запускает:
1. Frontend → `frontend/build`
2. Backend → `backend/dist`
3. Frontend билд копируется в бэкенд
4. Собираются Docker образы
5. Запускаются все сервисы в Docker

Ваше приложение будет доступно по адресу: `http://localhost:3000`

### Запуск в режиме разработки
```bash
pnpm start:dev
```

Это запускает:
- 🐳 MongoDB (Docker): `localhost:27017`
- 📦 Persistent Stories Volume (Docker)
- 🔧 Backend API (local): `http://localhost:3000`
- 🎨 Frontend Dev Server (local): `http://localhost:5173`

## Тестирование
```bash
pnpm test
```

Это запускает:
1. Backend и Frontend unit тесты
2. E2E тесты

**NB:** 
1. Для E2E-тестов используется отдельная база данных, она сидится тестовыми данными перед тестами и очищается после них. 
2. Также для E2E-тестов не обязательно держать запущенными Docker-контейнеры, так как они запускаются в рамках тестов.

## Архитектура Docker

### Сервисы
- **backend**: NestJS API, WebSocket сервер и раздача статики фронтенда (в production-режиме).
- **mongodb**: База данных для хранения пользователей, сообщений и метаданных историй; также есть отдельная база для тестов.
- **mongo-express**: Веб-интерфейс для управления базой данных (`http://localhost:8081`).

### Тома (Volumes)
- **mongo-data**: Постоянное хранилище для данных MongoDB.
- **stories-uploads**: Постоянное хранилище для медиафайлов историй (изображения и видео).

### Переменные окружения
Создайте `.env` файлы в соответствующих директориях:

**`backend/.env`:**
```env
MONGO_URI=mongodb://root:example@mongodb:27017/chat?authSource=admin
JWT_SECRET=supersecretkey
PORT=3000
```

**Корень проекта `.env` (для Docker Compose):**
```env
MONGO_USER=root
MONGO_PASSWORD=example
```
